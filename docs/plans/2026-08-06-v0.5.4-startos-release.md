# Buzz v0.5.4 StartOS Release Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Publish conventionally versioned `0.5.4:0` native Buzz StartOS packages and a verified public GitHub Release.

**Architecture:** Treat official `desktop-v0.5.4` as the upstream version and reset the downstream wrapper revision to zero. Tag a clean source commit, build both signed native packages once, then record their identities in a later evidence commit and publish those same bytes.

**Tech Stack:** TypeScript, Node test runner, Start SDK v2.0.9, `start-cli`, Git, GitHub CLI, SHA-256, Ed25519.

### Task 5: Tag And Build Native Packages

1. Create annotated tag `v0.5.4_0` on the clean source commit.
2. Regenerate `javascript/index.js` from that clean commit.
3. Pack x86_64 and aarch64 with command-scoped `-H http://localhost` so the
   offline pack is not coupled to a stale `.local` host profile.
4. Do not rebuild either archive after recording its identity.
