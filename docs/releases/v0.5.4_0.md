# Buzz for StartOS v0.5.4:0

This release packages the official Buzz Desktop `v0.5.4` server snapshot at
commit `651f6372754e60e3f936b3397040eb0f1e44c9f3` as StartOS version `0.5.4:0`.

## Included

- Native signed StartOS packages for x86_64 and aarch64.
- Patched, reproducibly rebuilt Buzz, MinIO, and MinIO Client runtime images.
- A dedicated root WebSocket pairing relay, preventing clients from deriving
  the unsupported `<main relay>/pair` route that returns HTTP 404.
- StartOS actions for initial setup, pairing-relay configuration, connection
  details, membership, recovery diagnostics, and maintenance.
- Buzz Desktop v0.5.4 server changes, including corrected NIP-11 limits and
  workspace-icon handling, multi-repository projects, safer Git default-branch
  deletion, and upstream dependency fixes.

## Important Compatibility Limits

- Remote mobile access is not supported by this package.
- In a private-CA `.local` setup, an unmodified Android client may reject the
  StartOS Root CA during secure pairing. Modifying the mobile app is not the
  intended long-term solution.
- Local desktop and ACP WSS access to a private StartOS address requires a
  client build that uses native trusted roots, with the StartOS Root CA
  installed on that computer.
- A future public-DNS, publicly trusted certificate, and StartTunnel/VPS design
  is planned separately for mobile interoperability.

## Qualification Status

The source, dependency, runtime-image, package, signature, and checksum gates
described in the repository are release prerequisites. Real x86_64 and
aarch64 StartOS installation, upgrade, backup/restore, client, and mobile
qualification remain separate Community Registry beta gates and are not
claimed by this GitHub release.

Verify both downloaded packages with `SHA256SUMS` before sideloading.
